# Tanishqa Studio | Portfolio

Animated portfolio website for Tanishqa (graphic design, video editing, motion graphics, AI content and web development).

Built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Files

- `index.html` : the whole website
- `assets/tanishqa.jpg` : profile photo

## Run locally

Open `index.html` in any browser.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<username>.github.io/<repo-name>/`.

## Edit

- Email, social links: search `index.html` for `tanu369.dev@gmail.com` and `yourhandle` / `yourname`.
- Work tiles are animated placeholders; replace them with real project images or videos.
